# 流量与筹码：孙宇晨与加密时代

> 一个争议企业家的成名、造币与全球牌局。

从惠州的考场与北大的公共讨论，到特斯拉、比特币、波场、巴菲特、艺术品和特朗普，再到景甜事件。一个名字如何被记住，一个身份如何变成信用，一笔钱如何进入下一场故事。

本书是一部以公开资料为事实骨架的**传记小说**，不是孙宇晨授权传记，也不声称还原其未公开的真实生活。书中未见于来源的对白、心理活动、环境细节与场景连接，均为文学化重构；公开事件、金额、时间与法律程序仍以文末资料为准。
