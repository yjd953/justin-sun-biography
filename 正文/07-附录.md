## 附录三　读者术语表

| 术语 | 含义 |
| --- | --- |
| 区块链 | 由网络依一定规则共同记录、核验数据的技术体系；不能保证记录外的陈述都真实 |
| 比特币 / BTC | 一种不代表普通公司股权的数字资产 |
| XRP | Ripple 相关网络涉及的数字资产；不要与 TRX 混写 |
| TRON / 波场 | 孙宇晨发起的区块链项目及网络 |
| TRX | 波场原生代币；价格与公司股权市值含义不同 |
| BTT | BitTorrent 相关代币，不等于购买开放协议的所有权 |
| HSR | 互换币故事中出现的 HCASH 早期代币名称 |
| USDT | Tether 发行、目标与美元挂钩的稳定币，可在不同链上运行 |
| USDD | 波场生态相关稳定币名称 |
| WLFI | World Liberty 的治理代币；早期不能自由转让 |
| USD1 | World Liberty 的美元稳定币项目，不等于 WLFI |
| `$TRUMP` | 特朗普品牌的迷因代币，与 WLFI 是不同项目 |
| ICO | 项目首次卖出代币融资的安排；不等于普通上市，也不自动合法 |
| 白皮书 | 项目解释目标、机制和安排的文件；不是已经兑现的成果证明 |
| 主网 | 已独立运行的区块链网络，相对测试环境而言 |
| 智能合约 | 按代码执行的程序；是否有修改和冻结权限，要看具体设计 |
| 代币解锁 | 原先受转让限制的代币按规则开放；不保证持有人都可立即卖出 |
| 做市 | 为买卖提供流动性的交易活动，不能与所有操纵或对倒直接等同 |
| 对倒 / wash trading | 没有真实权益变化却制造看似市场成交的交易；具体违法成立要看证据与规则 |
| 做空 | 通过某些交易安排从价格下跌获益；向交易所转账不单独证明做空 |
| 市值 | 按某种价格与数量相乘的估计值，不等于把全部资产卖出可拿到的钱 |
| 套现 | 将资产出售换得其他资产或货币；销售收入不等于净利润 |
| 时间加权持仓 | 同时看持有数量和时长的排名算法；不等于累计购买成本 |
| NFT | 能在链上区分具体代币的记录；不自动提供版权和所有图像使用权 |
| 立案 | 法院或机构接受进入相应程序，不意味着实体责任已经成立 |
| 财产保全申请 | 请求法院采取保全措施；申请和获准是不同阶段 |
| 管辖权异议 | 争论应由哪个法院审理；不直接决定谁胜诉 |
| 不承认也不否认 | 某些和解下当事人不就指控认罪或认事实，但接受约定的法律结果 |
| 终局撤诉 / with prejudice | 原则上不能再就相同请求重新起诉；不自动等于实体无罪判断 |
